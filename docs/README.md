# Rift — документация

Полу-независимая оверлейная сеть поверх обычного интернета: публичные ноды строят мосты,
ноды за NAT цепляются к ним, поверх всего — VPN, хостинг, домены `rift://` и кошелёк.

## Принципы

1. **Нода = ключ.** Идентичность — Ed25519-ключ, а не IP.
2. **Всё, что выдаёт власть, подписано и проверяемо оффлайн.** Control не обязан быть онлайн, чтобы ему верили.
3. **Control — нотариус, а не роутер.** Упал — сеть живёт.
4. **Всё, кроме control, — permissionless.**
5. **Не изобретаем криптографию и транспорт.** Изобретаем имена, доверие, оплату, UX.
6. **Одно ядро на Rust — все платформы.**
