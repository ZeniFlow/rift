# Кошелёк (фаза 5, начало)

Крейт `rift-wallet` и страница `browser://wallet` в браузере. Сеть TON, монеты: TON, USDT и jetton RIFT (W6, W8).
Решения W1–W13 в [README](README.md#решения).

## Что умеет

- Ключ создаётся на устройстве: 24 слова TON, кошелёк V4R2 (адрес совпадает с адресом других TON-кошельков по тем же словам).
- Слова хранятся только в `wallet.json` под паролем: Argon2id (64 МиБ, 3 прохода; параметры записаны в файле) и ChaCha20-Poly1305.
  Сеть и адрес входят в аутентифицируемые данные: подменить адрес или сеть в файле нельзя, расшифровка откажет.
  Файл создаётся с правами `0600`, пароль от 8 знаков.
- Баланс и история читаются без пароля (нужен только адрес). Отправка требует разблокировки; через 5 минут без действий ключ стирается из памяти.
- Перевод TON (с комментарием) и jetton'ов. Сумма разбирается точно, целыми числами по знакам монеты, без `f64`; адрес сети другого типа (тестовой в основной) отвергается;
  опечатка в адресе ломает его контрольную сумму. Перед окном подтверждения страница показывает разобранный адрес и точную сумму.
- Подпись живёт 5 минут (`valid_until`): зависшее сообщение потом не уйдёт. К jetton'у прикладывается 0.05 TON газа, остаток возвращается.
- Свои монеты: «Добавить монету» (тикер, знаки, адрес мастер-контракта), файл `tokens.json`. Так появится RIFT, когда его jetton будет выпущен.

## Чему доверяем

API сети (по умолчанию toncenter) может соврать о балансе или seqno, но не может подделать подпись или перенаправить деньги: сообщение собирается и подписывается локально.
Перед отправкой проверяются остаток монеты и TON на газ; при нехватке отправка не вызывается. Свой узел или другой сервер с тем же интерфейсом подставляется адресом API.
Ключи не покидают процесс; страницы сайтов к командам кошелька доступа не имеют (capabilities).

## Проверено

- `cargo test -p rift-wallet`: адрес V4R2 по известному вектору, шифрование и подмена файла, разбор сумм и адресов, подписанные сообщения разбираются обратно и проверяются открытым ключом,
  сценарии отправки против поддельного сервера с реальными ответами toncenter. Мутации (убрать проверку баланса, сети, адресата jetton'а, AAD) тесты ловят.
- `cargo test -p rift-wallet -- --ignored live`: чтение с настоящего toncenter (основная сеть).
- `rift-app selftest-ui`: создание, 24 слова, отправка с подтверждением, блокировка, неверный пароль (API поддельный).

## Что ещё нет

- Живой перевод в сети: нужен тестовый TON (бот-кран) и адрес; страница и подпись готовы, отправку в тестовой сети проверь руками.
- Jetton RIFT не выпущен: нужен контракт (мастер и кошелёк jetton'а), эмиссия по W10, казна по W13.
- История jetton'ов (показывается только TON), QR-код адреса, платёжные каналы для exit-нод (W9), оплата зон и стейк.
